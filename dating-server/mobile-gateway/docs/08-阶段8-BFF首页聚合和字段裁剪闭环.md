# 阶段 8：BFF 首页聚合和字段裁剪闭环

## 1. 阶段目标

完成 `/api/v1/bff/home?fields=profile,recommend_posts` 只读聚合闭环：网关根据鉴权上下文并行或顺序调用下游 gRPC，只在内存中组装 VO，支持一级字段白名单裁剪、必需字段保护、未知字段错误、部分失败降级和总超时控制。

## 2. 阶段类型

高耦合聚合切片。

## 3. 输入依据

- 最终方案第 8.1、8.2 章 BFF 职责边界。
- 最终方案第 9.2 章请求转发链路。
- 最终方案第 16.5 章 BFF 接口。
- 最终方案第 23、24、25 章可靠性、兜底和可观测性。

## 4. 输出结果

- `/api/v1/bff/home` 接口。
- `BffAggregateService` 首页聚合。
- `FieldProjectionConverter` 一级字段白名单裁剪。
- 必需字段不可裁剪；未知字段返回 `10801`。
- 非必需下游失败时返回 partial errors；必需下游失败时返回业务错误。
- BFF 聚合耗时 P95 / P99、部分失败次数指标。

## 5. 前置依赖

- 阶段 7：REST/gRPC 转换闭环。

## 6. 耦合度说明

- 耦合度等级：高耦合。
- 耦合度总分：8。
- 排序理由：BFF 聚合依赖认证上下文、多个下游只读 gRPC adapter、字段裁剪和降级策略，应在单 adapter 模式稳定后实现。

## 7. 数据库低耦合说明

本阶段不新增 `mobile-gateway` 表，不保存聚合结果。帖子、匹配、IM、支付等业务数据归属各自服务，网关不能直连它们的数据库、Redis key 或 MinIO bucket。

## 10. 详细任务拆分

### 任务 8.1：BFF home 契约和 VO

- 任务编号：8.1
- 任务名称：BFF home 契约和 VO
- 所属阶段：阶段 8
- 阶段类型：高耦合聚合切片
- 业务闭环：客户端可请求首页 BFF 聚合接口。
- 涉及文件：`BffController.java`、`HomeBffVO.java`
- 作用：定义 BFF 对外响应结构。
- 前置条件：阶段 7。
- 被阻塞于：阶段 7。
- 是否阻塞后续：是。
- 耦合度说明：对外接口本身中等耦合，后续聚合高耦合。
- 数据库变更：无。
- API / gRPC / MQ 契约：`GET /api/v1/bff/home?fields=profile,recommend_posts`。
- 实现要点：BFF 只读；不做跨服务写事务；VO 不暴露内部 `id`。
- 事务 / 幂等 / 一致性：只读，无事务。
- 异常和权限：未登录 `10100`。
- 验收标准：无 token 返回 `10100`；合法 token 进入聚合服务；响应包含 traceId。
- 验证方式：Web 集成测试。
- 是否 MVP 必做：是。
- 建议执行方式：AI 生成初稿。

### 任务 8.2：多下游只读聚合

- 任务编号：8.2
- 任务名称：多下游只读聚合
- 所属阶段：阶段 8
- 阶段类型：高耦合聚合切片
- 业务闭环：网关只读调用 user / post / match 等下游服务，组装首页数据。
- 涉及文件：`BffAggregateService.java`、各 gRPC adapter。
- 作用：提供首页聚合数据。
- 前置条件：任务 8.1、阶段 7。
- 被阻塞于：任务 8.1、阶段 7。
- 是否阻塞后续：是。
- 耦合度说明：依赖多个下游 gRPC mock。
- 数据库变更：无。
- API / gRPC / MQ 契约：下游只读 gRPC 方法，metadata 透传认证上下文。
- 实现要点：设置总超时和单调用超时；只在内存组装，不落库。
- 事务 / 幂等 / 一致性：只读聚合，无跨服务事务。
- 异常和权限：必需下游失败则整体失败；非必需下游失败返回 partial errors。
- 验收标准：多个下游 mock 成功时返回完整首页 VO；metadata 完整透传。
- 验证方式：gRPC mock 集成测试。
- 是否 MVP 必做：是。
- 建议执行方式：AI 辅助修改。

### 任务 8.3：一级字段裁剪

- 任务编号：8.3
- 任务名称：一级字段裁剪
- 所属阶段：阶段 8
- 阶段类型：高耦合聚合切片
- 业务闭环：客户端可通过 `fields` 只请求允许的一级字段。
- 涉及文件：`FieldProjectionConverter.java`
- 作用：减少 BFF 返回体积，保持字段白名单。
- 前置条件：任务 8.1。
- 被阻塞于：任务 8.1。
- 是否阻塞后续：否。
- 耦合度说明：本服务内部转换逻辑。
- 数据库变更：无。
- API / gRPC / MQ 契约：`fields` 只支持一级字段白名单。
- 实现要点：未知字段返回 `10801`；必需字段不可裁剪；裁剪发生在 VO 层。
- 事务 / 幂等 / 一致性：无。
- 异常和权限：未知字段 `10801`。
- 验收标准：请求 `fields=profile` 只返回 profile 和必需字段；未知字段返回 `10801`。
- 验证方式：单元测试、HTTP 测试。
- 是否 MVP 必做：是。
- 建议执行方式：AI 辅助修改。

### 任务 8.4：部分失败和超时降级

- 任务编号：8.4
- 任务名称：部分失败和超时降级
- 所属阶段：阶段 8
- 阶段类型：高耦合聚合切片
- 业务闭环：非必需下游失败时，首页仍可返回可用部分数据。
- 涉及文件：`BffAggregateService.java`、异常处理、VO。
- 作用：提升 BFF 可靠性。
- 前置条件：任务 8.2。
- 被阻塞于：任务 8.2。
- 是否阻塞后续：是。
- 耦合度说明：依赖多个下游异常路径。
- 数据库变更：无。
- API / gRPC / MQ 契约：partial errors 只暴露业务可理解信息，不暴露内部堆栈。
- 实现要点：必需字段失败返回业务错误；非必需字段失败返回空值和 partial errors；整体总超时可配置。
- 事务 / 幂等 / 一致性：只读，无事务。
- 异常和权限：BFF 部分数据失败使用 `10800` 或 partial errors。
- 验收标准：非必需下游超时返回部分数据；必需下游超时返回失败；响应 traceId 一致。
- 验证方式：异常注入测试。
- 是否 MVP 必做：是。
- 建议执行方式：AI 辅助测试。

## 12. 验收标准

- `GET /api/v1/bff/home` 需要鉴权。
- 所有下游成功时返回完整首页数据。
- `fields=profile` 只返回允许字段和必需字段。
- 未知字段返回 `10801`。
- 非必需下游失败时返回 partial errors。
- 必需下游失败时返回业务错误。
- BFF 聚合耗时 P95 / P99 和部分失败次数可采集。
